# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard built using Microsoft Power BI.

The dashboard analyzes employee data to provide insights into workforce composition, employee demographics, and employee attrition.

## 🎯 Objectives

- Analyze total employees
- Analyze employee attrition
- Understand employee demographics
- Analyze employee age groups
- Identify workforce trends
- Create interactive HR KPIs and visualizations

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## 📌 Dashboard Pages

### 1. Overview
Provides a high-level summary of the organization's workforce.

### 2. Employee Details
Provides detailed employee-level analysis.

### 3. Attrition
Analyzes employee attrition and termination patterns.
